# The Code
The code is mostly written in C++, with some c mixed in due to the compiler and language we chose, as it requires C code for backend and all graphics on the brain, like what we use for our auton selection.
## Language
We started on python, but realized that the libraries available through PROS and C++ in general would give us access to more complex and useful functions, so over winter break we made the choice to switch to PROS, and we had it up and running in a week.
## Planning
During the python code, all drivers expressed a preference for two-stick drive, so in PROS we went for that straight away

We "drew" out our skills route ahead of time, and then executed it in development

We chose to not put time into middle score, as it is complex and matches can be won without it

We plan to implement that, but for now that has been impacting our auton plans
